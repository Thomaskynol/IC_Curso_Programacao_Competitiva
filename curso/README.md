# Mapa inicial do curso

Proposta de sequência a partir da [reunião de 07/11/2026](../docs/reunioes/2026-11-07.md). Os títulos e a ordem dentro dos módulos são rascunhos para revisão. A unidade de produção é uma microaula com um objetivo, normalmente de 1 a 3 minutos.

## Módulo 1 — Introdução à programação competitiva

Apresentação sem código. O aluno conhece o formato dos desafios e aprende a localizar as informações importantes de um enunciado.

| ID | Microaula | Objetivo |
|---|---|---|
| M01-A01 | O que é programação competitiva? | Explicar o tipo de desafio que o curso ensina a resolver. |
| M01-A02 | OBI e InterIF | Situar as duas competições que orientam a escolha dos exercícios. |
| M01-A03 | Como ler um enunciado | Localizar o que o problema pede, as informações fornecidas e as regras. |
| M01-A04 | Como uma solução é avaliada | Mostrar conceitualmente que um avaliador roda a solução com diferentes casos. |

## Módulo 2 — Entrada, saída e problemas de cálculo

O aluno lê entradas, determina saídas e confere casos usando raciocínio matemático simples. A resolução no papel pode ser feita antes de qualquer código.

| ID | Microaula | Objetivo |
|---|---|---|
| M02-A01 | Como ler o formato da entrada | Identificar os valores, sua ordem e a divisão em linhas. |
| M02-A02 | Como escrever a saída esperada | Identificar o resultado e apresentá-lo no formato pedido. |
| M02-A03 | O que as restrições garantem | Usar os limites do enunciado para reconhecer entradas válidas. |
| M02-A04 | Resolvendo o Teleférico | Justificar manualmente a quantidade mínima de viagens em um exemplo. |
| M02-A05 | Criando casos de teste | Conferir o raciocínio com cabine cheia, sobra de alunos e uma única viagem. |

Exercício da sequência: [Teleférico adaptado](modulo-02-entrada-e-saida/teleferico.md).

Se for definido que este módulo também terá código, acrescentar aulas próprias para leitura, conversão de números e escrita da saída antes da primeira implementação. O caminho de resolução manual pode ser usado enquanto essa decisão estiver aberta.

## Módulo 3 — Python e condicionais

A lista assume que este módulo incluirá ou retomará o mínimo de Python necessário para executar os exemplos. A introdução à linguagem pode mudar de posição conforme a decisão do módulo 2.

| ID | Microaula | Objetivo |
|---|---|---|
| M03-A01 | Executando um primeiro programa em Python | Mostrar como executar um exemplo curto e observar o resultado. |
| M03-A02 | Variáveis e valores em Python | Guardar um valor e usá-lo em um exemplo curto. |
| M03-A03 | Comparações em Python | Avaliar uma condição como verdadeira ou falsa. |
| M03-A04 | Como usar if | Executar um trecho quando a condição é verdadeira. |
| M03-A05 | Como usar else | Tratar o caso em que a condição não vale. |
| M03-A06 | Como usar elif | Organizar decisões com mais de duas possibilidades. |
| M03-A07 | Resolvendo um problema de decisão | Traduzir uma regra do enunciado em condições e conferir a resposta nos limites. |

Complemento opcional para discussão com o orientador: match/case. A lista de exercícios e os módulos posteriores serão desenvolvidos em outra etapa.
