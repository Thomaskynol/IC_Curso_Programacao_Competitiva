# IC de Programação Competitiva

Projeto de iniciação científica no IFSP — Campus Araraquara, com orientação do Prof. Nunes. O objetivo é produzir um curso introdutório de programação competitiva em Python, com OBI e InterIF como referências.

O curso segue o formato MOOC e é organizado em módulos de microaulas. Cada vídeo trata de um objetivo específico e costuma durar de 1 a 3 minutos. Um exercício mais longo pode exigir mais tempo.
